SenseVoice STT 本地服务

使用 cc-haha 已下载的 SenseVoice Small (INT8) 模型，提供 OpenAI 兼容的本地转写接口。

OpenChamber 设置

模式 服务器（OpenAI 兼容）
服务器地址 http://127.0.0.1:47831
模型 sensevoice（任意非空值均可）
端点路径 保持默认 /audio/transcriptions，或填 /v1/audio/transcriptions
API Key 留空即可

启用步骤

  1. 打开 设置 → 语音 / 听写，把识别方式切到“服务器”。
  2. 按上表填写地址、模型和端点。
  3. 首次听写时服务会加载模型（约 2–3 秒），之后直接复用。

运行说明

本扩展注册了 service.keepRunning，随 OpenChamber 启动并常驻；空闲 5 分钟后会卸载模型释放内存，下次听写自动重载。

模型以 NTFS 硬链接放进扩展数据目录（同一磁盘时不额外占用空间）；sherpa-onnx 运行时首次会复制约 23 MB。因此 cc-haha 没有启动、甚至卸载后，本服务仍可独立工作。

可与 cc-haha 同时使用：两边各自加载一份模型，互不干扰，只是内存与 CPU 各占一份。

状态接口：http://127.0.0.1:47831/status（仅本机可访问）。

可选配置：%USERPROFILE%\.config\openchamber\guest-data\sensevoice-stt\config.json， 支持 port、modelDir、sherpaRuntime、 threads、language、idleUnloadMs。 例如端口冲突时写入 {"port": 47832}，并同步修改上面的服务器地址。
